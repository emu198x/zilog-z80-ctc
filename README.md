# zilog-z80-ctc

The Zilog Z80 CTC (Z8430) counter/timer circuit.

| Crate | Registry |
|---|---|
| [`emu198x-zilog-z80-ctc`](crates/emu198x-zilog-z80-ctc) | [crates.io](https://crates.io/crates/emu198x-zilog-z80-ctc) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Memotech MTX and Sord M5.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
